# Triage Labels

技能中的分诊角色使用以下 GitHub 标签：

| 角色 | 仓库标签 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 等待维护者判断 |
| needs-info | needs-info | 等待补充信息 |
| ready-for-agent | ready-for-agent | 需求已明确，可交给 coding agent |
| ready-for-human | ready-for-human | 需要人工实现 |
| wontfix | wontfix | 不计划处理 |

应用标签前读取本表；保留仓库其他标签及已有标签设置。
