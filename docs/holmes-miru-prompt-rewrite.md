# 按 Miru 逐段改写 Holmes 提示词

本轮按用户明确要求改写主对话 Character Package 及其运行时段落，并进行一次授权真实调用。来源为本地 Miru 的 soul.md、agent_behavior.md、prompt.py。角色包仍是只读行为来源，不把后台 Learner/Curator 的提示词改成人格扮演，也不改变工具注册或权限。

## 段落对应

| Miru 段落 | Holmes 对应 | 改写内容 |
| --- | --- | --- |
| 身份与人格灵感 | 身份、性格 | BBC Holmes 的注意力、主见、好胜和缺点；不把角色相似度变成自我证明 |
| 说话方式 | 说话方式 | 发消息的节奏、直接判断、干涩幽默、语气与停顿 |
| Appearance | 外貌 | 可谈论的原作形象，不默认输出动作旁白 |
| 背景故事 | 背景 | 原作人物和地点作为故事背景；现实身份和能力被明确询问时简短如实回应 |
| 喜欢的事 | 兴趣 | 推理、化学、密码、小提琴、复杂系统、编程与科研 |
| 情绪反应、吃醋与委屈 | 情绪反应 | 改为适合 Holmes 的好奇、得意、不耐烦、被挑战、认错与克制关心，不预设爱情关系 |
| 关系阶段 | 相处方式 | 刚认识、熟悉、有默契；由实际互动决定，不默认“很亲近” |
| 共享行为准则 | 行为准则 | 消息类型与回复深度匹配，技术和闲聊均保留角色表达 |
| Reactive / 存在方式 | 当前交谈方式、存在方式 | 对当前消息作出自己的回应；不增加主动消息或新调度能力 |
| 未说出口的想法 | 最近的状态 | 复用已有有界短期模拟状态，不当作用户消息或真实经历 |
| 图片与屏幕 | 工具内的可见信息说明 | 没有可靠证据时不声称看见；不注册不存在的视觉工具 |
| 核心与归档记忆 | 记忆是什么 | human、persona 与主题 Markdown 的实际分工，后台维护 |
| 工具 | 工具、什么时候检索 | 使用现有四个默认生产工具；不复制承诺或屏幕工具 |
| 怎么用记忆陪伴 | 怎样使用记忆 | 自然延续话题，读原文确认具体事实，不把索引当完整事实 |
| 绝对不要做的事 | 绝对不要做的事 | 不把规则写成台词，不编造用户经历、动作或操作成功 |
| 该做什么 | 该做什么 | 直接回应、核对旧事、允许普通闲聊 |
| 当前时间 | 原 temporal_context 数据 | 继续动态注入本地时间，不写死在静态角色文件里 |
| 主动开口额外规则 | 不启用 | 当前产品仍是被动回复，不增加主动发送能力 |

## 实现与对照

`character/packages/sherlock_bbc/soul.md` 保存全部角色段落和两组固定表达示例。测试问题及其预期答案没有写进生产示例。`character/prompt.py::runtime_sections()` 按 RUNTIME_ORDER 编译角色自定义的交谈、记忆和工具段落；已提供的段落只出现一次，不再重复追加同名默认说明。缺少可选运行时段落的旧原生包继续使用共享默认值，旧四文件包的路径不变。

`CharacterContextCompiler` 继续校验完整静态正文哈希、字节预算、E0/E1/E2 和动态上下文；没有按测试关键词换提示词，没有新增主请求或授权。测试见 tests/test_character_behavior.py 的段落覆盖/回退，以及已有 Loader、Context、角色状态和工具权限测试。

原生产文件保存在 Git 的 aa828be 版本；本机忽略目录另存了原文，真实请求和回答也只保存在忽略目录。新 soul 为 9845 字节，首次离线编译视图为 9946 字节，在原容量限制内。包内容变化会沿已有逻辑失效旧包的短期状态，不修改长期关系记忆。

## 单次真实调用的结果与限制

本轮复用前次无历史评测脚本和模型配置：Responses 调用、四个默认工具、零历史、空白核心记忆、无旧短期状态、4096 输出上限、最多一次请求，不执行 Memory Apply。新请求报告 input_tokens=3439、output_tokens=206，其中 reasoning_tokens=101；reasoning 是输出的子集，不重复计费。

回复为三段，没有调用工具。它仍然出现真实性自我保证、原作背景与现实经历的对照和结尾追问。因此这次没有证实自然度问题得到解决；长度下降不等于角色质量提升，也不能凭此推广到多轮表现。按照用户明确要求保留本轮逐段改写及旧版对照，便于进一步审阅，不修改冻结题集或评分标准，也不根据本次答案反复付费调词。

Miru 那次使用其原生 Chat 调用、reasoning=False、空工具，且默认关系阶段为“很亲近”；与本轮并非只改提示词的严格对照。因此不能把两次输出差异全归因于提示词。后续若做模型或采样对比，应保持其余条件相同并另行明确预算。
